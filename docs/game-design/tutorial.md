# チュートリアルの台本（PL-10）

初めて遊ぶ人（審査員を含む）が **1 分ほど** でルールを理解できるように、ゲームの最初に出す説明の台本です。実装は CD-16 です。

- 伝えることは 5 つだけです：押し付けられた「らしさ」／表と裏（見られているか）／お題をこなすと色が薄くなる／隠れて作ると色が濃くなる／勝ち方・負け方。
- セリフは ramen_chef（勇者 → 鶏白湯職人）の場合です。ほかのロールでは `{押し付けロール}` と `{なりたいロール}` を入れ替えます（下の「ロールが変わったとき」）。

> **ステータス：案（メンバー確認待ち）**

## 2. 決めたこと

- **本編の村で、本編の前に行う。** タイマー（`GameTimer`）は止め、村長以外の NPC は出さない（または止めておく）。チュートリアルの扇形は村長の 1 つだけにして、読む対象を減らします。
- **練習用の物を 2 つだけ置く。** スタート地点の近く（村長から数 m）に「練習用の素振り台」と「練習用の鍋」。本編のお題・レシピ・素材は使いません（素材は「ちょうど足りる数」しか置いていないため。items.md）。練習用の鍋は材料なしで作れて、何も持ち物に入りません。
- **数値は実際に動かして見せ、本編が始まるときに初期値に戻す。** 個性 50・平和度 70・進み具合 0（parameters.md）から始め直します。「色が薄くなる・濃くなる」を、目で見て分かるようにするためです。
- **「見つかる」は体験させない。** 見つかると平和度 -25 とびくっとする演出が入り、1 分に収まらないためです。#12 の文章とゲージで伝え、くわしくは結果画面のヒント（win-lose.md 4 章）に任せます。
- **#6 のお題は見られたままでよい**（npc.md 3 章：お題はらしくない行動ではない）。#9 の料理は、#8 で扇形の外に出てからにします。
- **2 回目からはスキップできる。** 発表やデモで何度も遊ぶので、タイトル画面か #1 で「スキップ」を選べるようにします（CD-16 への案）。

## 3. ロールが変わったとき（M2）

#1・#2・#14 は `RoleDefinition` から入れ替えます。ほかの文章はロールによらず同じです。

| # | 入れるもの |
|---|---|
| 1 | `RoleDefinition.imposedIntro`（村長のセリフ） |
| 2 | 「でも本当は……`{displayName}`になりたい！」 |
| 6 | 練習用の素振り台はそのまま使う（お題の練習なので、ロールの表のお題と同じでなくてよい） |
| 14 | 「制限時間は5分。`{displayName}`をめざそう！」 |

- #1 は「村長」の 2 字＋`imposedIntro`（「」込み）なので、`imposedIntro` は「」込みで 38 字以内にしてください。今の 4 ロールはいちばん長い progamer でも 31 字（#1 全体で 33 字）で収まっています（roles.md）。

## 実装する人へ（CD-16）

- ステップは上の表の順に 1 つずつ出します。「次に進む条件」は次のイベントで判定できます。

| 条件 | 判定 |
|---|---|
| キーを押す | 決定キー（Space / Enter、ゲームパッドは A） |
| 歩く（3m） | ステップが始まった位置からの距離 ≥ 3m |
| 歩く（視界の外） | `SurveillanceManager` の `IsPlayerWatched` が false になった |
| 調べる（E） | 練習用の物の `Interact` が終わった |
| 持ち物を開く（Tab） | 持ち物の画面を開いて、閉じた |

- 「練習用の素振り台」と「練習用の鍋」は `IInteractable` のチュートリアル専用の物で十分です（`IsSuspicious = false`、長押しの秒数は 2 秒）。本編の `TaskDefinition` / `RecipeDefinition` は作りません。
- 個性 -10・平和度 +10（#7）と個性 +15・進み具合 +30（#10）は、本編の `soup` と表のお題と同じ値（parameters.md）です。`PlayerParameters.Add()` で動かし、本編を始めるときに `GameBalance` の初期値に戻してください。
- 村長は #4 でプレイヤーのほうを向いて止まり、#8 以降はその向きのまま動きません（扇形の外に出られるように）。
- チュートリアル中は `GameEndJudge` の判定をしません（`GameManager.State` を `Playing` にしない）。
