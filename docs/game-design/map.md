# 村マップ・場所の一覧（DS-03）

村のどこに何があるか、NPC がどこを巡回し、どこが死角になるかを決めます。

- **場所の一覧**の表の場所IDは、CD-02 の `Spot_<ID>`（例：`Spot_kitchen`）と CD-09b の `spotId`（`TaskDefinition.targetSpotId`）にそのまま使います。
- 場所IDは PL-02（[tasks.md](tasks.md)）で仮に置いた ID を、**この文書で正とします**。名前は 1 つも変えていません（tasks.md・items.md・outfits.md・npc.md の直しは不要）。
- 広さは **40m × 40m**（CD-02 のブロックアウトと同じ）。座標は Unity の `(X, Z)`、**原点 = 広場の中心**、X が東・Z が北、1 = 1m です。
- 見た目は [art-direction.md](../art-direction.md)（DS-01）のとおり、村はくすんだ色、ロールの物だけロールの色です。配置図の色もそれに合わせています。

> **ステータス：案（メンバー確認待ち）**
> CD-02 のブロックアウトとまだ突き合わせていません。座標は「この配置ならルールが成り立つ」ことを確かめた目安です。CD-02 で動かした場合は、5 章の「巡回ルートの決まりごと」を守ったまま、この文書の座標を直してください。

## 3. NPC の巡回ルート

npc.md（PL-08）の 3 人・ルートの順番・止まる時間をそのまま使い、座標を決めました。ポイント名は CD-02 の `RouteN_i` です。3 本とも `loop = true`、`moveSpeed = 2`、視界 8m・90 度、止まると ±60 度見回す（CD-08a / CD-08b）。

| ルート | ポイント（順番）と座標 (X, Z) | 止まる時間 | 1 周 |
|---|---|---|---|
| `Route1` 村長 `chief` | `Route1_0` 村長の家の前 (0, 9.5) → `Route1_1` 広場の北 (0, 4) → `Route1_2` 訓練場の入口 (9, 6) → `Route1_3` 広場の南 (0, -4) → 最初へ | **4 秒** | 約 37 秒 |
| `Route2` 見張り `guard` | `Route2_0` 広場の東 (6, 0.8) → `Route2_1` 井戸 (11, 1.5) → `Route2_2` 畑の道ばた (8, -9.6) → `Route2_3` 森の入口 (16.6, -5) → `Route2_4` 訓練場の裏 (16.6, 12) → 最初へ | 2 秒 | 約 39 秒 |
| `Route3` おかみ `cook` | `Route3_0` 食堂の中 (-11.5, 1) → `Route3_1` 食堂の倉庫 (-11.5, 6.5) → `Route3_2` 裏口 (-15.6, 1.5) → `Route3_3` 食堂の前 (-7, 1) → `Route3_4` 広場の西 (-4, -1.5) → 最初へ | 2 秒 | 約 26 秒 |

- 1 周の秒数は、まっすぐ歩いた場合の計算です（曲がる・止まるときの減速は入っていません）。npc.md の目安（35 / 50 / 40 秒）より少し短めです。
- **`Route3_2`（裏口）では、おかみは台所の方（西）を向いて見回す**ようにします。歩いてきた向きのままだと南西を向き、台所が視界の端にしか入りません。CD-08a で「ポイントごとに向きを決められる」が無い場合は、`Route3_2` の少し東に向きを決めるための点を足してください。
- おかみは食堂の中を歩きます。食堂には窓が無いので、中にいる間は外が見えません（倉庫と食堂の中だけを見ている）。
- 村長は広場の真ん中を十字に行き来し、見張りは村の東半分を大きく回り、おかみは西の食堂と広場の間を行き来します。**西の端（台所・裏の道）と南西（実家・納屋）は、だれのルートからも外れています。**

## 6. バランスの確認

40m × 40m に上の配置・ルート・視界（8m・90 度、止まると ±60 度見回す、建物は視線をさえぎる）を置いて、真上から見た 2D の計算で「1 周のうち何秒見られているか」を確かめました。10 分ぶん動かした結果です。高さ・NavMesh の曲がり方・プレイヤーの体の大きさは入っていないので、目安です。CD-02 / CD-08a ができたら実際に動かして確かめてください。

| 場所 | 見られている割合 | 続けて見られない最長の時間 | 見ている人 |
|---|---|---|---|
| 作業台 `kitchen` | 約 4% | **約 24 秒** | おかみ（裏口にいる 2 秒だけ） |
| 井戸の水 `water` | 約 27〜30% | 約 16 秒 | 見張り・村長 |
| 食堂の倉庫（小麦粉・エプロン） | 約 16〜18% | 約 19 秒 | おかみ |
| 畑の鶏ガラ `chicken_bone` | 約 4% | 約 47 秒 | 見張り |
| 広場 `plaza` | 約 37% | 約 10 秒 | 3 人とも |
| 森の奥の頭タオル | 0% | － | なし |

- **どの作業台にも、見られずに使えるタイミングがある**：`kitchen` の続けて見られない時間は約 24 秒で、npc.md の決まりごと 1（8 秒以上）を満たします。鶏白湯ラーメン（5 秒）も、移動を入れて間に合います。
- **素材は見られやすい場所にも置く**：水は 3 割近く見られている井戸、小麦粉とエプロンはおかみが 2 か所で止まる倉庫にあります。どれもタイミングを見ないと拾えません。
- **お題の場所は NPC の近く**：訓練場の入口は村長の止まる場所、食堂はおかみのルート上、村長の家の前は村長の止まる場所です（npc.md の決まりごと 4・5）。

### 巡回ルートの決まりごと（配置を動かすときも守る）

npc.md の 1〜5 に、この配置で決めたことを足しました。

1. 作業台 `kitchen` は、1 周のうち 8 秒以上続けて誰からも見えない時間がある。
2. 素材は見られやすい場所にも置く（井戸・倉庫・畑の奥）。
3. 死角は森の奥・食堂の裏・畑の奥の 3 つ。
4. お題の場所（`training_ground` `canteen` `chief_house`）は NPC のルートの近く。
5. 村長の家と見張りの通り道は離しすぎない（見張りは広場の東 `Route2_0` まで来る）。
6. **（追加）** 台所へは食堂の中を通らずに行ける道（裏の道）を残す。
7. **（追加）** おかみは `Route3_2` で台所の方を向く。

## 7. 決まっていないこと・確認すること

- **CD-02 のブロックアウトとまだ合わせていない。** この座標でブロックを置けるか、CD-02 の担当と一緒に確かめて、ずれたらこの文書を直す（Issue の完了条件）。
- **台所が少しやさしすぎるかもしれない。** すきが約 24 秒あるので、3 つのレシピ（3 + 3 + 5 秒）を 1 回のすきで全部作れてしまいます。むずかしくするなら、`Route3_2` の止まる時間を延ばすか、裏口を `Route3` に 2 回入れる。遊んでみてから決めます。
- **M2 の西側（実家・納屋・鍛冶場・書庫）を見る NPC がいない。** librarian を足すときの親方 `blacksmith`（鍛冶場の前）と、band_man / progamer 用にもう 1 本ルートを足すかを M2 で決めます。M2 の素材の置き場所も仮です。
- 1 周の秒数が npc.md の目安より短い（とくに見張り 39 秒・おかみ 26 秒）。止まる時間はそのままにして、実際に歩かせてから決めます。
- 配置図は計算で描いた図です。建物の形・木の位置は DS-07 で 3D アセットに置き換えるときに変えてかまいません（場所ID・道・死角の位置は変えない）。
