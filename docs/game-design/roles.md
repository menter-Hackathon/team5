# ロール一覧（PL-01）

押し付けられる「らしさ」と、プレイヤーが選べる「なりたいロール」の一覧です。
各ロールの表はそのまま `RoleDefinition`（`Assets/_Project/Data/Roles/Role_〇〇.asset`）のデータになります。列は変えないでください。

> **ステータス：案（メンバー確認待ち）**
> 「元ネタのメンバー」で「※要確認」と書いたものは仮です。本人の好きなもの・地元を聞いて差し替えてください。
> Issue #1 に全員の👍がついたら確定とします。

## まとめ

| 作る順番 | roleId | なりたいロール | 押し付けられる「らしさ」 | 作る時期 |
|---|---|---|---|---|
| ★ 1 | `ramen_chef` | 鶏白湯職人 | 勇者 | MVP（M1） |
| 2 | `dancer` | ダンサー | 長男 | M2 |
| 3 | `painter` | 絵描き | 鍛冶屋の跡取り | M2（余裕があれば） |
| 4 | `inventor` | からくり職人 | 農家の子 | 余裕があれば |

- **MVP は `ramen_chef`（★）**。設計書（architecture.md）のサンプル名（`Role_RamenChef` / `Recipe_PaitanSoup` / `Item_ChickenBone`）とそろっているので、コード担当が仮データのまま進めやすい。また「素材を集めてスープを作る」は裏の行動（集める→クラフト）がいちばんわかりやすい。
- M2 では 2 → 3 の順に 1〜2 個追加する（11/17 の会議で最終決定）。
- 色は、ロール同士を並べても見分けやすいように、オレンジ・ピンク・青・緑で分けた。
