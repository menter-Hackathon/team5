# デバッグで確認するポイント（11/20 コードフリーズ前）

遊んで気づいたことは Discord #main か Notion に「どこで・何をしたら・どうなった」を書く。
F1 のデバッグパネルで「残り時間を 10 秒に」「材料をもらう」「パラメーター操作」が使える。

## 1. 通しで遊べるか（最優先）

- [ ] タイトル → ゲーム → 結果 → タイトル に戻れる（何回くり返しても止まらない）
- [ ] クリア（鶏白湯職人への進み具合 100）で「クリア！」の帯 → 結果画面
- [ ] 平和度 0 で「ゲームオーバー（村にばれてしまった…）」
- [ ] 個性 0 で「ゲームオーバー（色が消えてしまった…）」
- [ ] 5 分たつと「タイムアップ」。F1 → 残り 10 秒で確認
- [ ] 結果画面の数字（時間・お題の数・見つかった回数など）が実際と合っている
- [ ] 2 回目のプレイで前回の持ち物・ゲージ・お題が残っていない

## 2. お題（村長）

- [ ] 素振り → 辛ラーメン → 薪 3 本 → 見張りに報告 の順に出る
- [ ] E 長押しの動作（素振り・食べる）がその場所でだけできる
- [ ] 制限時間内にやらないと失敗になり、平和度が −15
- [ ] ごほうび（小麦粉・水）が持ち物に入る
- [ ] 地図の目的地マーカーがいまのお題の場所を指している

## 3. 見張り（NPC）

- [ ] 扇形に入ると右上の目が「見られている！」になる。壁・建物の向こうからは見えない
- [ ] 見られている間に拾う・作る・道から外れると見つかる。見つかったら平和度 −25（3 秒は連続で減らない）
- [ ] 見つかった NPC がこちらを向く動きが自然（いきなりくるっと回らない）
- [ ] NPC が建物・柵に引っかかって止まったり、壁にめり込んだりしない
- [ ] きつすぎ／ゆるすぎないか（クリアまでに何回見つかったかをメモ）

## 4. 素材・クラフト

- [ ] 鶏ガラ ×2（畑の奥）・水（井戸）・薪 ×3（森の入口）が拾える
- [ ] 作業台（台所）で 鶏ガラスープ → 手打ち麺 → 鶏白湯ラーメン が作れ、進み具合 +30/+30/+40
- [ ] 作っている間に見つかると中断し、材料が消えない
- [ ] Tab の持ち物表示が実際の数と合う

## 5. 村・移動・カメラ

- [ ] 村のどこにも落ちる穴・すり抜ける壁・出られなくなる場所がない（村の端・森・畑の柵ぞい）
- [ ] 建物（食堂・家・納屋・台所）に入ると屋根が消え、出ると戻る
- [ ] 見えない壁（昔の箱の当たり判定）にぶつからないか。逆に見た目はあるのに通り抜けられる物がないか
- [ ] 止まっているときに待機モーション（呼吸・見回し）が出る。歩き↔止まるの切り替えが自然
- [ ] 個性 20 未満で足が遅くなる

## 6. UI・文字

- [ ] 文字が欠けていない・□（豆腐）になっていない。特に珍しい漢字
- [ ] 小さい画面（1280×720）と大きい画面でも UI が重ならない・はみ出さない
- [ ] ミニマップ（左下）と全体地図（M キー / クリック）が開閉でき、自分の向き・NPC・目的地が正しい
- [ ] Esc の一時停止、F1 パネルが本番の操作のじゃまにならない
- [ ] チュートリアル・吹き出しの文の誤字

## 7. 音

- [ ] BGM がシーンをまたいで二重に鳴らない・途切れない
- [ ] 見つかったとき・クラフト・お題成功/失敗の SE が鳴る
- [ ] 音量が大きすぎない

## 8. WebGL（unityroom）だけで起きやすいこと

- [ ] 読み込みが最後まで進む（Chrome・Safari・Edge）
- [ ] 最初のクリックまで音が鳴らないのは仕様（ブラウザの制限）。クリック後は鳴る
- [ ] 日本語の文字が出る（フォントの読み込み）
- [ ] フレームレートが落ちすぎない（NPC が多い場所・全体地図を開いたとき）
- [ ] Esc でフルスクリーン解除・マウスが外れても操作が戻る
- [ ] Tab キーでブラウザのフォーカスが移らない

## 9. 報告のしかた

- 再現手順（どこで・何をしたら）・期待した動き・実際の動き・スクショか動画
- 1 回だけ起きたものも書く（「たまに」も大事）
