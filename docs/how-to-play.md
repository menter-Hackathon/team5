# 遊び方（MVP・11/19 会議用）

「〇〇らしく」を求められる村で、言われたとおりに振る舞いながら、見られていない隙に「本当になりたい自分」へ変わっていくゲームです。MVP のロールは **鶏白湯職人**（押し付けられる「らしさ」は勇者）。

## 起動のしかた

| 方法 | 手順 |
|---|---|
| Unity で遊ぶ | main を pull → Unity 6000.0.85f2 で開く → `Assets/_Project/Scenes/Title.unity` を開いて ▶ |
| ビルドで遊ぶ | 配られた `RashisaNoMura_Win64.zip` を展開 → `RashisaNoMura.exe`（Windows） |

## 操作

| キー | 動作 |
|---|---|
| WASD / 矢印 | 移動（画面の上 = W） |
| E | 拾う・渡す・話しかける・作業台を開く |
| E 長押し | お題の動作（素振り・食べる） |
| Tab | 持ち物 |
| Esc | 一時停止 |
| F1 | デバッグパネル（パラメーターを直接いじる・残り時間を 10 秒に・材料をもらう） |

## ルール

- **左上のゲージ 3 本**
  - 個性の濃さ：お題をこなすと −10、クラフトで +15〜20。0 で負け、20 未満で足が遅くなる
  - 村の平和度：お題をこなすと +10、失敗で −15、らしくない行動を見られると −25。0 で負け
  - 鶏白湯職人への進み具合：クラフトで +30 / +30 / +40。**100 でクリア**
- **村長のお題**（左のカード）：素振り → 辛ラーメンを食べる → 薪を 3 本届ける → 見張りに報告、の順に出る。制限時間内にやらないと失敗
  - 「辛ラーメンを食べる」をこなすと **小麦粉**、「見張りに報告」をこなすと **水** がもらえる（これがないと鶏白湯が作れない）
- **見られている／いない**（右上の目）：NPC の足元の扇形に入ると「見られている！」。見られている間に **拾う・作る・道から外れる（畑・森の奥）** と見つかる
- **作業台**（食堂の裏の台所）：鶏ガラスープ（鶏ガラ×2・水）→ 手打ち麺（小麦粉・水）→ 鶏白湯ラーメン（スープ・麺）。作っている間に見つかると中断
- 制限時間は 5 分

## 素材の場所

| 素材 | 場所 |
|---|---|
| 鶏ガラ ×2 | 畑の奥（禁止ゾーン。見張りに注意） |
| 水 ×1 | 井戸のそば（もう 1 つはお題のごほうび） |
| 小麦粉 | お題「辛ラーメンを食べる」のごほうび |
| 薪 ×3 | 森の入口（お題用。拾っても見つからない） |
| エプロン・頭タオル | 食堂の倉庫・森の奥（着替えは未実装） |
