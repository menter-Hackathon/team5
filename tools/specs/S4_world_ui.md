=== DS-01 ===
## 目的
メンバーの好きなものを混ぜた世界観を「見た目のルール」にする。このあとのデザイン作業はすべてこれに合わせる。

## 会議で決まっていること
- クラシックな 3D 見下ろし型のゲームの村（山あいの村・キャンプ場のような雰囲気も案に出た）
- NPC やアイテムはカジュアルなデフォルメ（ポケモン系のイメージに近い）
- オブジェクトは立体、移動は平面だけ、カメラは角度固定

## 作るもの
`docs/art-direction.md` に次をまとめる（画像は `docs/images/` に置く）
1. **参考画像** 5〜10 枚と、それぞれ「どこを参考にするか」（Miro の画像を使ってよい）
2. **画風**：ポリゴン感（ローポリ / なめらか）、輪郭線の有無、影の付け方
3. **カラーパレット**（色コードで書く）
   - 村・押し付けられた「らしさ」側の色（くすんだ色 3〜4 色）
   - 個性・なりたいロール側の色（あざやかな色 3〜4 色）
   - UI の色（背景・文字・強調・警告）
4. **フォント**：見出し用・本文用（無料で商用可のもの。例：M PLUS Rounded 1c、Noto Sans JP）
5. **メンバーの好きなもの・地元**から村に入れる要素の一覧（例：横浜の港、大阪の食べ物 など。全員に聞く）
6. 1 枚にまとめたムードボード画像 `docs/images/moodboard.png`

## 完了条件
- [ ] docs/art-direction.md に 1〜6 がそろっている
- [ ] チームの Discord で共有し、反対がない

=== DS-03 ===
## 目的
村のどこに何があるか、NPC がどこを巡回し、どこが死角になるかを決める。ゲームの面白さ（隙を見て動く）を左右する。

## 作るもの
- `docs/images/map.png`：上から見た配置図（手書きを撮影したものでもよい）
- `docs/game-design/map.md`：場所の一覧

## 仕様
- 広さ：40m × 40m（CD-02 のブロックアウトと同じ）
- 配置図に書くもの
  - 場所：広場、村長の家、食堂、作業台、畑、森、そのほかロールに必要な場所（PL-02 のお題の場所）
  - 道（決められた道）
  - NPC の巡回ルート 3 本（矢印）と、立ち止まる場所
  - **死角**（建物の陰など、見られずに裏の行動ができる場所）を色を変えて塗る
  - 素材を置く場所（ロールごとに色分け）
- map.md の表：`場所ID（英語） | 名前 | 何をする場所か | 関係するロール`（場所IDは CD-02 の `Spot_<ID>` と CD-09b の spotId に使う）
- **バランスの目安**：どの作業台にも、見られずに使えるタイミングがある。ただし素材は見られやすい場所にも置く

## 完了条件
- [ ] 配置図と場所の一覧がある
- [ ] CD-02 の担当と一緒に、ブロックアウトに反映した

=== CD-14 ===
## 目的
ゲーム中に必要な情報を画面に出す。

## 作るもの
- `Scripts/UI/HudView.cs`、`Prefabs/UI/HUD.prefab`（Game シーンの Canvas に置く）
- これまでの仮 UI（TaskView、WatchedIndicatorView、InteractPromptView）を HUD.prefab にまとめる

## 仕様
- 最初は仮の見た目（Unity 標準の Image と TextMeshPro）で、DS-08 のデザインが来たら差し替える
- 表示とつなぎ先
  | 表示 | データ |
  |---|---|
  | 残り時間「m:ss」 | GameTimer.OnTick |
  | ゲージ 3 本 | PlayerParameters.OnChanged / GetNormalized |
  | お題 | TaskManager.OnTaskAssigned / Completed / Failed、Current.TimeRemaining |
  | 見られているか | SurveillanceManager.OnPhaseChanged |
  | 見つかった通知 | SurveillanceManager.OnCaught |
  | 操作ヒント | PlayerInteractor.OnFocusChanged |
- ゲージは値が変わったとき 0.3 秒かけて動く。下がったときは赤く点滅
- 残り 30 秒で時間の文字を赤くする
- **毎フレーム文字列を作らない**（OnTick では秒が変わったときだけ更新する）

## 完了条件
- [ ] 上の表の情報がすべて画面に出て、正しく更新される
- [ ] DS-08 のデザインに差し替えてある（デザインが間に合わない場合は仮のままで、別 Issue にする）

## 確認手順

=== CD-20 ===
## 目的
会議で「プレイヤーが自分でなりたいロールを選ぶ」と決まったので、ロールを選ぶ画面を作る。

## 作るもの
- `Scripts/UI/RoleSelectView.cs`、Title シーン内の「ロール選択」パネル
- `Data/Roles/RoleCatalog.asset`（`RoleCatalog : ScriptableObject`：選べるロールの一覧 `List<RoleDefinition> roles`）

## 仕様
- タイトルの「はじめる」→ ロール選択パネル → ロールを選んで「このロールを目指す」→ `GameManager.StartGame(選んだロール)`
- 各ロールのカードに出すもの：displayName（なりたいロール）、押し付けられる「らしさ」（imposedRoleName）、短い説明（RoleDefinition に `[TextArea] string description` を追加してよい）、ロールの色、完成時の衣装の画像（あれば）
- ロールが 1 つしかないときはこの画面を飛ばす
- キーボード（←→ と Enter）とゲームパッドで選べる

## 完了条件
- [ ] ロールを選んでゲームを始めると、そのロールのお題・レシピになる

## 確認手順
1. ロールを 2 つ用意し、それぞれを選んでゲームを始め、お題が違うことを確認
